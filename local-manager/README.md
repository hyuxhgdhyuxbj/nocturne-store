# NOCTURNE 本地店铺管理器

这个程序把商品资料和图片保存在当前电脑的 `manager-data` 文件夹，不依赖 Supabase。

## 使用方法

1. 确认电脑已安装 Node.js。
2. 双击 `start-manager.cmd`。
3. 浏览器打开后，在商品编辑器里添加商品。
4. 图片和视频可以一次选择多张；第一张是商品封面。
5. 在「规格参数」里填写材质、尺寸、身高、体重等信息。
6. 在「可选规格」里填写颜色、尺码等选项。
7. 点击「保存并预览」检查客户看到的页面。
8. 全部商品完成后点击「导出静态站」。

你只需要记住两个地址：`http://127.0.0.1:4310/` 是你自己的本地管理器，负责添加和修改商品；GitHub Pages 地址是客户访问的静态商城，只负责展示。客户地址里不会出现「新商品」或管理入口。

最简单的日常流程是：在本地管理器添加商品和媒体 → 点击「保存并预览」 → 手机上打开预览检查 → 确认无误后告诉我「已导出」，我再把 `manager-data/publish` 的完整内容同步部署到 GitHub。你不需要再把商品逐件发给我，也不需要使用云端后台。

日常追加商品时，继续打开同一个管理器即可。今天保存的 50 件商品会保留，明天新增的 50 件商品会写入同一个完整目录；每次导出都会重新生成整站，不会因为日期不同而覆盖旧商品，也不会产生商品编号冲突。商品编号由程序自动生成并保持不变。

商品删除可以在左侧商品列表直接点击「删除」，也可以进入商品后点击右上角「删除商品」。删除后先从目录中移除，下一次导出时会自动清理该商品不再使用的图片和视频。导出前程序会自动保留最近 5 次静态站备份，误操作时可以从 `manager-data/backups` 找回上一版。

修改图片、规格或介绍后请点击「保存商品」；关闭页面前如果还有未保存内容，浏览器会提醒。导出结果会同时写入 `export-info.json`，记录导出时间、商品数量和媒体数量。

静态网站会生成在：

```text
local-manager/manager-data/publish
```

这个 `publish` 文件夹就是以后上传到 GitHub Pages 的客户网站文件。客户访问静态站时不需要 Supabase，也不需要 VPN。

本地管理器只在你的电脑上使用，不再要求店铺登录。客户网站只显示商品、分类、图片、视频和客服微信，不包含管理入口。
